# 대학전선 · OLYMPUS v3.0

올림푸스 신전을 모티브로 한 메인 화면과 세 대학의 3D 동시 턴 전략 전장입니다. 플레이어는 성균관대, 고려대와 연세대는 AI입니다. 비공식 팬 프로젝트입니다.

## 현재 제공하는 게임

- 21×21 지도, 30턴 점수전, 3진영과 7거점.
- 12개 연구, OP/RP 경제, 개발·특화, 병력 모집, 방어 시설과 휴전.
- 한 번 탐험한 지형은 계속 보이며, 적 병력은 현재 시야 안에서만 표시.
- 성균관대 56동, 고려대 172동, 연세대 232동의 데이터 기반 캠퍼스. 각 캠퍼스는 4×4칸에 공통 수평 축척으로 축소됩니다. 현실의 최신 건물 전체를 보증하지 않습니다.
- 기존 v13 캠페인 자동 저장을 유지합니다.

## 이번 변경

- 대리석·남색·금색 UI와 직접 제작한 신전 일러스트. 진입 경로는 3D 전장 하나입니다.
- 별도 2D PvE/PvP, P2P 연결, 채팅·랭킹 코드와 메뉴를 제거했습니다. 과거 코드는 Git 이력에 남습니다.
- 시점 슬라이더 35~75도, 기본58도. 드래그는 지도 이동, 휠·핀치는 확대입니다.
- 정사영 화면 크기를 실제 캔버스 표시 영역과 일치시키고 수평 축척을 유지합니다. 낮은 각도에서 생기는 자연스러운 원근 단축은 남지만 지형이나 캠퍼스 X/Z를 따로 늘리지 않습니다.
- 보병·정찰·기병·공성 병과의 실루엣, 진영별 받침 모양·색, 병과/체력 표식. 건물에 가린 부대도 표식으로 선택할 수 있습니다.
- 장식 건물 높이 축소, 차분한 지형색, 대학별 경계와 캠퍼스 바로가기.

## 실행 및 검증

`node server.mjs` → http://127.0.0.1:49383/ (PORT 환경변수 지원)

`npm test` → 전투·성장·시야·외교·저장·캠퍼스 형상·카메라·조작 회귀 검사.

브라우저에서 데스크톱 및 390×844 화면, 입장/홈 복귀, 저장된 2턴 재개, 모집/턴 종료, 35/75도 조절, 세 대학 확대를 확인했습니다. 8개 화면 비율 × 3개 각도 × 6개 확대에서 화면 축척이 같음을 자동 검사합니다. 실제 모바일 GPU/터치 하드웨어 성능은 별도 검증이 필요합니다.
