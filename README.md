# 대학전선 (Campus Frontier) — 플레이 가능 모바일 대응 알파 v0.1.1

기획서 「대학전선 상세 게임 기획서 v2.0」의 19.1절에 해당하는 기능부터 구현한 **PC 웹 싱글플레이 전략 게임 시제품**입니다. UI는 한국어입니다.

## 실행하기 (Windows / macOS / Linux)

**필수:** Node.js 18 이상. 패키지 설치(`npm install`)가 필요하지 않습니다.

Windows에서는 압축을 푼 뒤 `start-windows.bat`을 더블클릭하세요.

또는 프로젝트 폴더에서 터미널을 열고 다음을 실행하세요.

```bash
node server.mjs
```

크롬·엣지 등의 브라우저에서 **http://localhost:4173** 을 여세요. 더블클릭으로 `index.html`을 직접 열면 브라우저 보안 정책으로 로컬 모듈·JSON을 불러오지 못할 수 있으므로 **서버로 실행**하세요.

테스트 실행:

```bash
node --test test.mjs
```

## 의도적으로 빠진 기능

이 버전은 **기획서 v2.0 전체의 완성판이 아닙니다.** 다음은 아직 구현하지 않았습니다.

- 대학별 고유 능력·전문화 분기, 외교·연합·휴전
- 서버 온라인 동기화 / 친구와 대전 / 계정 / 실시간 채팅
- 실제 서울 공간 전체의 지형·도로 재현 및 실제 위치의 다중 대학
- 원본 고해상도 지형과 수천 개 나무, 도로 111개
- 시야 제한(Fog of War), 전체 12기술 연구, 고급 시설 건설·수리
- 세부 작업 슬롯, 안정화, 모든 이동 경로의 다단계 충돌·자리 교환
- WebGL 기반 자유 카메라의 실시간 3D 엔진
- 화면을 직접 조작하는 브라우저 통합 QA 및 실제 모바일 최적화

3D로 보이는 지도는 **HTML5 Canvas 사선 투영 방식(2.5D)** 입니다. 폴리곤 윤곽과 높이를 그려 돌출형 건물로 표현하지만 Three.js/WebGL 메시 렌더링을 사용하지 않습니다. 따라서 이 버전을 정밀 실측 3D 게임이라고 부르지 않습니다.

## 플레이 방법

1. 민트색 유닛을 클릭합니다.
2. **이동** 버튼으로 이동 가능한 타일을 클릭하면 이동이 예약됩니다. 정찰대는 한 턴에 최대 2 이동력입니다.
3. 거점(황금 ◆) 위에 올라가 다음 턴 **점령** 명령을 내리면 소유권을 얻습니다.
4. 적이 인접하면 **공격** 버튼을 누른 뒤 적을 선택할 수 있습니다.
5. 오른쪽에서 모집(턴당 1개)과 연구를 예약합니다.
6. **턴 실행** 버튼으로 AI와 아군의 턴을 함께 처리합니다.
7. 최대 15턴에 도달하거나 한 진영만 남으면 경기 종료. 살아 있는 진영의 점수로 승자를 결정합니다.

카메라: 상단 회전/줌 버튼, 마우스 휠, 드래그. 단축키 Q/E 회전, Esc 선택 해제.

## 구성

- `engine.mjs`: 결정적 턴 판정 규칙, AI, 자원, 승리 점수
- `renderer.js`: 사선 투영 지도, 건물·거점·부대 렌더링
- `game.js`: 브라우저 입력, 명령 UI, 저장·복원, 화면 갱신
- `data/skku-buildings.json`: 56개 건물 윤곽 경량화 자료
- `index.html`, `style.css`: UI
- `test.mjs`: Node 내장 테스트 러너용 규칙 테스트
- `server.mjs`: 정적 로컬 HTTP 서버

## 개발상 주의

- 자동화된 엔진 테스트는 통과했지만, 작업 환경 브라우저 접근 제한으로 사용자 인터페이스의 실제 브라우저 클릭 검증 및 목표 FPS 측정까지는 완료하지 못했습니다.
- AI는 시제품용 탐욕적 휴리스틱입니다. 전략적인 적을 완전히 구현한 것이 아닙니다.
- 각 부대가 선택한 최종 타일에서 충돌하는 기본 규칙만 구현했습니다. 다단계 이동 경로 충돌은 후속 작업입니다.
- 저장은 브라우저마다 분리되며, 서버로 저장 데이터를 전송하지 않습니다.


## 스마트폰으로 플레이 (GitHub Pages)
이 게임의 브라우저용 정적 파일(`index.html`, `game.js`, `engine.mjs`, `renderer.js`, `style.css`, `data/`)은 GitHub Pages에 그대로 배포할 수 있습니다. Node 서버는 로컬 개발용이며 호스팅에는 필요하지 않습니다.

1. GitHub에서 새로운 **public** 저장소를 만듭니다(예: `campus-frontier`).
2. 이 폴더 안의 파일들을 저장소 **최상위(root)**에 업로드/커밋합니다. ZIP 파일 하나만 업로드하면 게임으로 서비스되지 않습니다.
3. 해당 저장소 `Settings > Pages > Build and deployment`에서 `Deploy from a branch`, `main`, `/ (root)`를 선택하고 저장합니다.
4. 배포 완료 시 `https://<GitHub 아이디>.github.io/campus-frontier/` 형태의 주소로 휴대폰과 PC에서 접속할 수 있습니다.

휴대폰에서는 지도 한 손가락 드래그, 두 손가락 핀치 확대/축소, 화면 우하단 턴 실행, 화면 하단 고정 부대 명령을 사용합니다. 모바일 실기기 성능 검증과 화면 접근성 개선은 여전히 추가로 필요합니다. 저장 기록은 기기·브라우저별로 독립적입니다.
