# 대학전선 · 동시 턴 전략 v0.5

성균관대의 전체 데이터 기반 축소 캠퍼스를 3×3 전장 타일에 담은 싱글플레이 전략 시제품입니다.

## 실행과 확인

- `node server.mjs` → http://127.0.0.1:49383/
- `node test.mjs` 및 `node growth-test.mjs` → 전투·성장·카메라·56개 건물 모형 검사
- 웹 플레이: https://gwonjae06-droid.github.io/campus-frontier/

## 캠퍼스

`data/skku-campus.json`의 건물 56개를 모두 렌더링합니다. 전체 건물과 캠퍼스 경계의 바깥 범위로 하나의 공통 수평 축척을 계산합니다. 캠퍼스 외곽은 3×3 타일 안에 들어가고 건물의 상대적 위치·윤곽을 유지합니다. 고도는 축소하며 건물 높이는 식별을 위해 1.3배 강조합니다. 이름 없는 건물도 제외하지 않습니다. 확대 시 건물을 누르면 원본 데이터의 이름·층수·높이가 나옵니다.

데이터에 포함된 모든 건물을 유지한다는 뜻이며, 현실의 모든 최신 건물 현황을 보증하지 않습니다. 다른 대학은 동일한 데이터 인터페이스로 확장할 수 있지만 현재 실제 캠퍼스는 성대만 포함합니다. 적은 가상의 AI 전초기지입니다.

## 턴 규칙 (기획 v2.0 부분 반영)

- 이동 / 공격 / 방어 / 점령 / 회복 중 부대당 주명령 하나. 미명령은 대기하며 자동 공격하지 않습니다.
- 보병 HP10·공격4·방어2·이동1, 정찰 HP7·공격2·방어1·이동2. 숲 비용2·엄폐1, 보병은 인접 숲 한 칸 진입 가능.
- 공격 대상은 예약 시 지정하고 실행 시 다시 사거리 검사합니다. 최소 피해1, 방어 +1, 동시 피해. 회복은 자기 영토에서 +2, 피격 시 취소.
- 거점은 도착한 다음 턴 점령 명령 필요. 중립은 다음 턴부터 수입, 적 거점은 한 턴 안정화 후 수입.
- 시작 OP10, 기본 수입5, 정상 거점2. 캠퍼스 HP30. 모집 보병5/정찰4, 성벽3/방어탑7.
- 캠퍼스 작업 슬롯1. 모집은 네 접점에서만, 접점에 성벽/탑 금지. 부대 상한6+정상거점(최대10), 본진 탑 최대2.
- 방어탑은 두 턴 작업 후 다음 턴부터 사거리2·공격3. 공사 중에는 반투명으로 표시하고 슬롯을 점유합니다.
- AI는 현재 확정 상태만으로 명령 결정. 실제 OP를 소비해 한 턴에 한 부대 모집하며 상한 적용.
- 턴 결과는 연출 전에 원자적으로 저장합니다. 이전 저장은 보존하고 별도의 v4 저장으로 새 연습 시작.

## 연구·거점 성장·카메라 (v0.4)

- 연구5종: 자원 개발6 RP → 거점 전문화10 RP, 조직 훈련6 RP, 방어 건축6 RP → 방어 체계16 RP.
- 본진 RP3/턴. 연구 미선택/초과분 최대10 보관, 기술별 진행 보존, 한 턴 한 기술 완료. 연구 완료 효과는 다음 턴부터 적용합니다.
- 조직 훈련은 방어 명령 보정+2. 성벽과 방어탑은 각각 방어 건축/방어 체계로 해금합니다.
- 자원 개발: 캠퍼스 및 두 거점에 자원 타일 각각1개. OP3·1턴, 다음 턴부터 OP+1. 부대 통행 가능.
- 정상 거점의 경제(OP+2)/연구(RP+2) 특화: OP6·1턴, 한 번만 선택. 점령 후 보존하며 안정화 후 산출합니다.
- 각 거점은 개발/특화 작업 슬롯1개, 캠퍼스 개발은 병력·방어시설 슬롯을 공유합니다. 예약 취소는 전액 해제, 작업 방해는50% 환급.
- RP는 턴 시작 상태에서 산출을 확정합니다. 그 턴 신규 연구 특화를 적용하지 않습니다. AI도 연구와 거점 경제 특화를 실제 비용으로 진행합니다.
- 카메라: 좌우 드래그 회전, 위아래 드래그/슬라이더 25~75도 기울기, 휠 확대. 집 버튼으로 각도46도·북동 시점·전체 전장 복귀. 회전 버튼은90도 단위입니다.
- 높은 시점에서 전체 지도 기본 여백을 보정합니다. 캠퍼스 확대 시에도 각도 조절 가능. 드래그 거리 누적 상태로 클릭과 구분합니다.

## 이번 반영 범위와 차이

15×15, 실제 성대1 + 가상 전초기지1, 공개 시야 연습전입니다. 21×21·3진영·7거점·15/30턴 점수제·나머지7기술·군사 특화·연구시설·대학 특성·외교는 미구현입니다. 거점 병력 모집/시설 건설·생산 대기·완전한 영토 귀속도 후속입니다. AI는 일부 연구/거점 경제 특화를 사용하며 캠퍼스 개발과 방어 시설은 아직 운영하지 않습니다. 이동은 시작 시 점유 칸을 통과하지 못하고 목적지가 겹치면 양쪽 대기하며, 단계별 충돌 교전/아군 순환 이동은 아직 없습니다. 정찰 이동 연출은 출발점과 도착점을 잇는 선으로 재생합니다. 공사 중 탑은 타일을 차지하는 임시 장애물로 표시됩니다. 작은 단계의 기획 반영이며 v2.0 전체 구현 완료를 뜻하지 않습니다.

## 구성

- `simulation.js`: 렌더링 및 시계와 독립적인 턴 판정
- `campus.js`: 원본 지리 데이터에서 모든 건물·지형 생성
- `board.js`: 3D 전장, 선택, 예약 표시, 결과 애니메이션
- `game.js`: 조작·예약·저장·화면 상태
- `growth.js`: 연구·개발·거점 특화
- `camera.js`: 카메라 각도 범위와 궤도 계산

## 현재 범위

온라인 동기화, 대학별 공동 자원, 공통 시간 제한, 다중 대학 데이터, 실시간 채팅은 미구현입니다. 현재 턴 실행 버튼으로 로컬의 아군과 AI를 동시에 처리합니다. 서버 통합 시 명령 제출과 확정 상태의 권한을 서버로 옮겨야 합니다. 실기기 터치·성능 및 장기 밸런스는 추가 검증 대상입니다.

## v0.5: 7개 거점과 15턴 점수 승리

- 기존 3D 시각 스타일과 실제 성균관대 56개 건물 데이터를 그대로 유지합니다.
- 15×15 연습전에 일반 거점 6곳과 중앙 주요 거점 1곳을 배치했습니다. 중앙 거점은 일반 거점과 같이 OP +2/턴을 주며, 점수 계산에서는 5점(일반 3점)입니다. 중앙 거점은 특화하지 못합니다.
- 양측 본진이 15턴까지 생존하면 일반 거점 3점, 중앙 거점 5점, 완성 연구 2점, 생존 본진 5점으로 점수 승패를 결정합니다. 본진 함락은 즉시 승패 판정합니다. 동점은 연습 모드에서 무승부로 처리하며 30턴 기본전의 상세 타이브레이커는 아직 없습니다.
- AI는 동일 거점에 모든 부대를 집중시키지 않도록 이번 턴의 목표를 분산합니다.
- 카메라 상하 각도 범위를 18~80도로 확대했으며 낮게(22°)·높게(72°) 버튼을 추가했습니다. 회전/확대/기본 시점 버튼은 유지됩니다.
- 기존 v4 저장은 건드리지 않고, 다른 저장 키(v5)로 새 연습을 시작합니다. 기획서 전체 21×21, 3진영, 12기술, 외교 및 온라인은 아직 미구현입니다.
