# 대학전선 · OLYMPUS v4.0 — 순차턴 3D 대학 전략게임

기본 게임은 순차 턴제로 전환됐습니다. 플레이어가 선택한 대학이 먼저 행동하고, 나머지 두 대학 AI가 **순서대로** 행동합니다. 이전 동시턴 엔진 `simulation.js`와 자동 테스트는 과거 버전 호환용으로 보존했으며, 현재 메인 화면은 `sequential-app.js` / `sequential-mode.js`를 사용합니다.

## 핵심 게임 흐름

1. **대학 선택**: 성균관대 인문사회과학캠퍼스 / 고려대 안암캠퍼스 / 연세대 신촌캠퍼스 중 선택합니다. 해당 대학의 실제 4×4 시작 위치 및 부대를 조작합니다.
2. **원터치 이동·전투**: 아군 부대를 누르면 이동·공격 가능한 칸이 표시됩니다. 칸을 누르면 즉시 행동하며 부대 하나가 라운드당 1회 행동할 수 있습니다.
3. **거점 자동 점령 및 성장**: 7개 고정 거점은 진입 즉시 점령됩니다. 보유 거점 Lv.1 → Lv.2 → Lv.3 성장 시 거점 수입이 +2 → +4 → +6 OP/라운드로 증가합니다.
4. **OP 단일 통화**: 병력 모집, 거점 발전(5/10 OP), 4개 계열의 3단계 연구를 OP로 구매합니다. 별도 RP를 조작하지 않습니다.
5. **대학별 특성**: 성균관대 연구 할인, 고려대 인접 아군 방어 보너스, 연세대 점령 거점당 OP +1 연결망 보너스.
6. **부분 랜덤 맵**: 21×21 기본 지형과 세 4×4 실제 캠퍼스, 7개 핵심 목표는 유지하되 중립 지역의 추가 자원 보너스 10개 위치가 게임 시드에 따라 바뀝니다. 탐사 후 자원 위에 도착하면 OP를 획득합니다.
7. **순차 라운드**: ‘내 턴 종료’ 뒤 두 AI 진영이 **차례로 현재 상태에 근거해** 이동·공격·모집·성장합니다. 이후 다음 라운드 수입을 획득하며, 30라운드 후 최종 점수로 승리합니다.

21×21 정사영 3D 전장, 성균관대 56동 / 고려대 172동 / 연세대 232동 OSM 건물 외곽 자료, 4×4 캠퍼스, 탐험 안개 및 부대 3D 모델을 보존했습니다.

### 저장·검증
- 신규 저장 키: `campus-frontier-sequential-v4` (버전 14).
- 과거 `campus-frontier-turn-v13` 저장은 **변경하지 않으며** 자동으로 새 규칙에 이식하지 않습니다.
- `npm test`는 기존 자동 테스트 및 신규 `sequential-test.mjs`를 실행합니다.
- 현재 공개 게임: https://gwonjae06-droid.github.io/campus-frontier/

실제 모바일 GPU의 FPS와 터치 UX는 자동 Node 테스트만으로 보장되지 않습니다.

## v4.1 — 아카데미 연구창 리디자인

- OLYMPUS 3D 순차턴 전략의 연구 화면을 **4계열 × 3단계 연결식 기술 트리**로 교체했습니다. 각 노드를 누르면 오른쪽(모바일에서는 아래)에 **미니멀 SVG 기술 삽화**, 실제 연구 효과 2가지, 비용/완료/잠김 상태, 구매 버튼이 표시됩니다.
- 색상은 저채도 아이보리·연녹색·잉크·절제된 금색이며, 글로우나 번쩍임 없이 440px 이하 화면에서도 한 열로 정렬됩니다. 작은 화면은 세로 스크롤을 사용합니다.
- **효과 설명은 sequential-mode.js의 실제 연산 기준**: 경제 +2 OP/라운드, 군사 공격력 +1/단계·2단계 기병·3단계 공성대, 방어 1단계 휴식 회복 +1·2단계 부대 방어 +1/본진 피해 -1·3단계 휴식 회복 +1, 학문 연구 비용 -1/단계(최소 3 OP)·2단계 아군 시야 +1칸. 미래 단계 OP 비용은 현재 할인 기준 예상값으로 표시됩니다.
- 기존 순차턴 규칙, OP, 게임 저장 키와 3개 대학 캠퍼스는 변경하지 않습니다. 새로운 Node 회귀 테스트 `research-panel-test.mjs`를 추가했습니다.
- 웹 애니메이션/모바일 GPU 시각 검증은 자동 회귀검사 외에 별도 실기기 확인이 필요합니다.

## v4.2 — 전투 UX 개선

- 선택한 부대의 체력·공격력·방어력·이동력을 보여주며 공격 가능 대상의 예상 피해를 공유 계산식으로 산출합니다.
- 대학별 AI 행동을 실제 순차 스냅샷으로 재생합니다. 1×/2× 배속과 건너뛰기는 화면만 바꾸며 전투 결과는 동일합니다.
- 게임 진행 중 전투 보고서에 관측 가능한 거점·전투·자원 이벤트와 내 점수(거점·본진·연구)를 표시합니다. 미확인 상대 점수는 비공개입니다.
- 전투 기록은 세이브 버전 14를 변경하지 않고 별도 `campus-frontier-battle-log-v42` localStorage 키에 보존합니다.
- `battle-ux-test.mjs`가 피해 미리보기/이벤트 안개 필터링/대학별 순차 이벤트를 확인합니다.
- 모바일 UI 및 실기기 FPS는 최종 자동 테스트 외에 실제 화면 확인이 필요합니다.
