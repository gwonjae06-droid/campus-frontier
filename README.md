# 대학전선 · PvE/PvP 라이벌 아레나 v2.0

성균관대의 전체 데이터 기반 축소 캠퍼스를 3×3 전장 타일에 담은 싱글플레이 전략 시제품입니다.

## 실행과 확인

- `node server.mjs` → http://127.0.0.1:49383/
- `node test.mjs` 및 `node growth-test.mjs` → 전투·성장·카메라·56개 건물 모형 검사
- 웹 플레이: https://gwonjae06-droid.github.io/campus-frontier/

## 캠퍼스

`data/skku-campus.json`의 건물 56개를 모두 렌더링합니다. 전체 건물과 캠퍼스 경계의 바깥 범위로 하나의 공통 수평 축척을 계산합니다. 캠퍼스 외곽은 3×3 타일 안에 들어가고 건물의 상대적 위치·윤곽을 유지합니다. 고도는 축소하며 건물 높이는 식별을 위해 1.3배 강조합니다. 이름 없는 건물도 제외하지 않습니다. 확대 시 건물을 누르면 원본 데이터의 이름·층수·높이가 나옵니다.

데이터에 포함된 모든 건물을 유지한다는 뜻이며, 현실의 모든 최신 건물 현황을 보증하지 않습니다. 다른 대학은 동일한 데이터 인터페이스로 확장할 수 있지만 현재 실제 캠퍼스는 성대만 포함합니다. 적은 가상의 AI 전초기지입니다.

## 턴 규칙 (기획 v2.0 부분 반영)

- 이동 / 공격 / 방어 / 점령 / 회복 중 부대당 주명령 하나. 미명령은 대기하며 자동 공격하지 않습니다.
- 보병 HP10·공격4·방어2·이동1, 정찰 HP7·공격2·방어1·이동2. 숲 비용2·엄폐1, 보병은 인접 숲 한 칸 진입 가능.
- 공격 대상은 예약 시 지정하고 실행 시 다시 사거리 검사합니다. 최소 피해1, 방어 +1, 동시 피해. 회복은 자기 영토에서 +2, 피격 시 취소.
- 거점은 도착한 다음 턴 점령 명령 필요. 중립은 다음 턴부터 수입, 적 거점은 한 턴 안정화 후 수입.
- 시작 OP10, 기본 수입5, 정상 거점2. 캠퍼스 HP30. 모집 보병5/정찰4, 성벽3/방어탑7.
- 캠퍼스 작업 슬롯1. 모집은 네 접점에서만, 접점에 성벽/탑 금지. 부대 상한6+정상거점(최대10), 본진 탑 최대2.
- 방어탑은 두 턴 작업 후 다음 턴부터 사거리2·공격3. 공사 중에는 반투명으로 표시하고 슬롯을 점유합니다.
- AI는 현재 확정 상태만으로 명령 결정. 실제 OP를 소비해 한 턴에 한 부대 모집하며 상한 적용.
- 턴 결과는 연출 전에 원자적으로 저장합니다. 이전 저장은 보존하고 별도의 v4 저장으로 새 연습 시작.

## 연구·거점 성장·카메라 (v0.4)

- 연구5종: 자원 개발6 RP → 거점 전문화10 RP, 조직 훈련6 RP, 방어 건축6 RP → 방어 체계16 RP.
- 본진 RP3/턴. 연구 미선택/초과분 최대10 보관, 기술별 진행 보존, 한 턴 한 기술 완료. 연구 완료 효과는 다음 턴부터 적용합니다.
- 조직 훈련은 방어 명령 보정+2. 성벽과 방어탑은 각각 방어 건축/방어 체계로 해금합니다.
- 자원 개발: 캠퍼스 및 두 거점에 자원 타일 각각1개. OP3·1턴, 다음 턴부터 OP+1. 부대 통행 가능.
- 정상 거점의 경제(OP+2)/연구(RP+2) 특화: OP6·1턴, 한 번만 선택. 점령 후 보존하며 안정화 후 산출합니다.
- 각 거점은 개발/특화 작업 슬롯1개, 캠퍼스 개발은 병력·방어시설 슬롯을 공유합니다. 예약 취소는 전액 해제, 작업 방해는50% 환급.
- RP는 턴 시작 상태에서 산출을 확정합니다. 그 턴 신규 연구 특화를 적용하지 않습니다. AI도 연구와 거점 경제 특화를 실제 비용으로 진행합니다.
- 카메라: 좌우 드래그 회전, 위아래 드래그/슬라이더 25~75도 기울기, 휠 확대. 집 버튼으로 각도46도·북동 시점·전체 전장 복귀. 회전 버튼은90도 단위입니다.
- 높은 시점에서 전체 지도 기본 여백을 보정합니다. 캠퍼스 확대 시에도 각도 조절 가능. 드래그 거리 누적 상태로 클릭과 구분합니다.

## 이번 반영 범위와 차이

15×15, 실제 성대1 + 가상 전초기지1, 공개 시야 연습전입니다. 21×21·3진영·7거점·15/30턴 점수제·나머지7기술·군사 특화·연구시설·대학 특성·외교는 미구현입니다. 거점 병력 모집/시설 건설·생산 대기·완전한 영토 귀속도 후속입니다. AI는 일부 연구/거점 경제 특화를 사용하며 캠퍼스 개발과 방어 시설은 아직 운영하지 않습니다. 이동은 시작 시 점유 칸을 통과하지 못하고 목적지가 겹치면 양쪽 대기하며, 단계별 충돌 교전/아군 순환 이동은 아직 없습니다. 정찰 이동 연출은 출발점과 도착점을 잇는 선으로 재생합니다. 공사 중 탑은 타일을 차지하는 임시 장애물로 표시됩니다. 작은 단계의 기획 반영이며 v2.0 전체 구현 완료를 뜻하지 않습니다.

## 구성

- `simulation.js`: 렌더링 및 시계와 독립적인 턴 판정
- `campus.js`: 원본 지리 데이터에서 모든 건물·지형 생성
- `board.js`: 3D 전장, 선택, 예약 표시, 결과 애니메이션
- `game.js`: 조작·예약·저장·화면 상태
- `growth.js`: 연구·개발·거점 특화
- `camera.js`: 카메라 각도 범위와 궤도 계산

## v0.5: 7개 거점과 15턴 점수 승리

- 기존 3D 시각 스타일과 실제 성균관대 56개 건물 데이터를 그대로 유지합니다.
- 15×15 연습전에 일반 거점 6곳과 중앙 주요 거점 1곳을 배치했습니다. 중앙 거점은 일반 거점과 같이 OP +2/턴을 주며, 점수 계산에서는 5점(일반 3점)입니다. 중앙 거점은 특화하지 못합니다.
- 양측 본진이 15턴까지 생존하면 일반 거점 3점, 중앙 거점 5점, 완성 연구 2점, 생존 본진 5점으로 점수 승패를 결정합니다. 본진 함락은 즉시 승패 판정합니다. 동점은 연습 모드에서 무승부로 처리하며 30턴 기본전의 상세 타이브레이커는 아직 없습니다.
- AI는 동일 거점에 모든 부대를 집중시키지 않도록 이번 턴의 목표를 분산합니다.
- 카메라 상하 각도 범위를 18~80도로 확대했으며 낮게(22°)·높게(72°) 버튼을 추가했습니다. 회전/확대/기본 시점 버튼은 유지됩니다.
- 기존 v4 저장은 건드리지 않고, 다른 저장 키(v5)로 새 연습을 시작합니다. 기획서 전체 21×21, 3진영, 12기술, 외교 및 온라인은 아직 미구현입니다.

## v0.6: 공성대·기동대·연구 시설 및 모바일 제스처

- **공성 기술(12 RP)**: 조직 훈련 후 공성대를 해금합니다. 공성대는 HP8/공격3/방어1/이동1/사거리2이며, 시설·본진 대상 추가 피해 +3입니다. OP9 및 캠퍼스 생산 2턴이 필요하고, 거점 점령은 할 수 없습니다.
- **기동 전술(16 RP)**: 조직 훈련 후 기동대를 해금합니다. 기동대는 HP9/공격4/방어1/이동2, OP8, 캠퍼스 생산 2턴입니다.
- **연구 방법(8 RP)**: 본진 또는 안정화된 거점에서 연구 시설 건설을 해금합니다. OP6, 2턴 건설 후 다음 턴부터 RP+1을 제공합니다. 거점별 1개입니다.
- 보병·정찰대의 기존 규칙과 연구 진척은 유지합니다. 새 연구를 포함해 **현재 총 8개 기술**이 있습니다.
- 모바일에서는 **두 손가락으로 벌려 확대, 오므려 축소, 두 손가락을 함께 밀어 지도를 이동**할 수 있습니다. 확대 슬라이더와 확대·축소 버튼(0.7~7배), 기본 시점 복귀 버튼도 사용할 수 있습니다. 한 손가락 드래그로 시점을 회전하고 기울입니다.
- 모바일 모집 도구는 가로로 스크롤하여 공성대/기동대까지 선택합니다.
- 화면/터치 이벤트 계산을 게임 판정과 분리하고 수학 및 턴 규칙 자동 테스트를 추가했습니다.
- 기존 v5 플레이 데이터는 그대로 두고 v6 저장 키로 새 연습을 시작합니다. 현재 **15×15 싱글 1대1 연습전**이며, 최종 기획서의 **21×21, 3진영, 12기술, 대학별 특성, 외교, 온라인**은 아직 미구현입니다. 실기기 터치 테스트는 별도 확인이 필요합니다.

## v0.8 — 정식 기본전 구조에 가까운 확장 단계

- **전장 21×21, 최대 30턴**: 성균관대 3×3 실제 캠퍼스 데이터 56개 건물 유지. 상대 AI 캠퍼스도 3×3 지상형 미니어처와 네 공격 접점으로 변경. 일반 거점 6개 + 중앙 1개는 서로의 본진에 가까운 지역에 분산 배치했습니다.
- **공통 기술 12종**: 광역 관리(16 RP), 도로망(10 RP), 전문 연구(14 RP), 종합 프로젝트(20 RP) 신규 추가. 기존 연구 8종과 비용·선행 조건을 유지합니다.
- **실행 가능한 신규 성장 규칙**: 광역 관리로 소유 중인 일반 거점 한 곳의 영토를 거리 2까지 확장합니다. 도로망을 연구하면 OP1로 자기 영토의 도로를 건설하며, 해당 타일 진입 비용은 1이 됩니다. 군사 특화 거점을 보유하면 현재 연습전에서는 캠퍼스 정예 병과 모집 시간을 1턴 줄입니다(거점별 모집 구현 전 임시 적용).
- **종합 프로젝트**: 전용 연구를 완료한 뒤 본진 슬롯에서 OP15·3턴 투자. 완공 시 승리 점수 +10점. 새 게임마다 최대 한 번입니다.
- **결산**: 30턴 종료 시 점수 동점이면 본진 HP → 정상 거점 수 → 연구 완료 수 순서로 비교합니다.

- 지도에서는 아군 부대를 탭해 **초록 칸으로 이동, 보이는 적을 탭해 공격**합니다. 거점에 도착한 생존 부대는 점령 명령 없이 **자동 점령**합니다. 두 AI도 같은 점령 규칙이 적용됩니다.
- 게임 전면 UI는 **보병 모집(5 OP) / 정찰 모집(4 OP) / 취소 / 턴 종료**의 4개 버튼으로 축소했습니다. 캠퍼스 출전 빈 자리는 자동으로 선택되며, 연구 미선택 시 합리적인 기본 순서에 따라 자동 연구합니다. 상세 생산·점령·명령 예약·외교는 기존 정보 메뉴에 남아 있습니다.
- 연구 버튼을 누르면 **경제·전투·방어·학문** 성장 경로 네 개가 먼저 보이며, 완전한 스킬 트리/거점 특화는 접힌 고급 메뉴로 열 수 있습니다.
- 성균관대 1명 대 연세대·고려대 AI의 기존 21×21/30턴 경기를 유지하며 저장 키는 `campus-frontier-turn-v13`으로 새 게임을 시작합니다. 과거 로컬 저장은 그대로 보존됩니다.
- 성능: Android/iOS 작은 화면에서 렌더링 픽셀 비율 제한, 건물 모서리선 생략, 나무/도로 데이터 샘플링; 실제 스마트폰 FPS 및 터치 UX 검증은 별도로 필요합니다.
- 출처와 재배포 조건: `data/THIRD-PARTY-GEO-DATA.md` 참조. 변환된 두 데이터셋은 ODbL 1.0에 따라 공개합니다.

## v1.4 — 캠퍼스 3D 비율·높이·시점 보정

- **세 캠퍼스 모두 실제 게임상 4×4 타일(16칸)**을 유지합니다. 렌더러가 캠퍼스 윤곽/건물 위치에 X/Z 독립 축척을 적용하지 않고, 원본 데이터 범위 중 긴 축을 4.12월드 단위 안에 동일한 축척으로 배치합니다. 이 방식은 신촌/안암 캠퍼스가 가로로 빈 부분이 생겨도 원본 지도 비율은 변형하지 않습니다.
- 축소 과정에서 건물 높이가 매우 낮아진 문제를 수정했습니다. 건물 **가로·세로는 실제 지리 데이터의 상대 비율을 유지**하고, 높이만 게임 가시성에 맞게 0.11~0.82단위로 표현하도록 보정했습니다(`campus-scale.js`). 따라서 건물의 높이는 실측 축척을 정확히 재현한 것이 아닌 **게임용 스타일화**입니다.
- 성균관대·연세대·고려대 건물 지면은 기존 보정 높이와 지면 경계 아래에서부터 시작하며 별도 두꺼운 받침대가 없습니다. 4×4 캠퍼스 테두리를 세 진영 모두 같은 크기로 표시해 점유 범위를 식별하기 쉽습니다.
- 기본 카메라 피치를 46° → 61°로 올려 사선에서 지면이 과도하게 눌려 보이는 문제를 줄였습니다. 시점 슬라이더로 이전 각도 및 다른 각도를 자유롭게 선택할 수 있습니다.
- **대학명 라벨**은 캔버스 512×90의 실제 종횡비에 맞게 3.65×0.642로 조정해 글자가 가로로 늘어나 보이지 않도록 했습니다.
- 브라우저 캐시 갱신용 `v14` 파일 버전을 부여하고 기존 전투·연구·3진영·모바일 테스트 및 새 `campus-proportions-test.mjs`로 X/Z 비율, 4×4, 3D 바닥, 높이, 카메라, 라벨을 검증합니다.
- 기존 v13 저장 키와 플레이 규칙은 유지합니다. 모바일 실기기에서의 시각적·FPS 확인은 별도로 필요합니다.

## v1.6 — 선명한 아이소메트릭 현대 대학도시

- 전장 시점은 56°의 고정형 아이소메트릭 구도를 기본으로 사용하며 드래그·슬라이더로 50°~62° 사이만 부드럽게 조정됩니다. 가로 회전도 ±7.5°로 제한하고 회전 버튼은 작은 각도로만 움직입니다. 정사영으로 캠퍼스 모델 가로세로 왜곡을 방지합니다.
- 기존 임의의 픽셀·종횡비 기반 카메라 폭 계산을 제거하고, 21×21 월드 타일의 실제 카메라 투영 폭과 높이를 뷰포트 비율에 맞춰 계산합니다. 시작 확대 배율을 1.08로 설정해 화면에서 맵의 존재감을 높였습니다. 좁은 모바일에서는 지도를 확대하고 패닝하면서 탐색할 수 있습니다.
- 지형은 포화도가 높은 숲·도시 녹지·산·하천·자원 색상으로 바꿨습니다. 성균관대는 녹색, 연세대는 파란색, 고려대는 적색으로 캠퍼스 지면, 건물 지붕·외벽, 4×4 경계와 병력에 공통 적용합니다.
- 현대 도시 분위기의 연속적인 아스팔트 도로(차선·보도·횡단보도)와 선택된 육상 타일의 아파트·상가형 건물을 절차적으로 렌더링합니다. 기존 지형, 시야, 이동, 점령과 저장을 변경하지 않는 시각적 도시화입니다. 즉, 도로의 시각적 표시는 기존 기술 도로망의 이동력 효과와 별개이며 아파트는 장식용입니다.
- 캠퍼스 내부 실제 OSM 도로 경로는 픽셀에 의존하는 얇은 GL 선 대신 폭이 있는 지면 리본으로 그려 확대·축소해도 식별되도록 했습니다.
- 더 또렷하고 대비 높은 야외 풍경 및 반투명 HUD, 모바일 확대 조작 유지. 원본 참고 이미지나 타 게임의 아트/텍스처는 복제하지 않았습니다. 이용한 게임 규칙, 실제 캠퍼스 지도 데이터, 저장 v13 형식은 그대로입니다.
- modern-city-test.mjs에서 시점 각도와 맵 투영 왜곡 방지, 도시 도로·아파트 배치, 대학별 색상/테두리·캠퍼스 4×4 및 브라우저 코드 연결을 검사합니다. GitHub 자동 테스트는 실제 기기 GPU/FPS 테스트와 다릅니다.

## v1.7 — 전략 지도 시점 고정 및 한 손가락 스와이프 이동

- **일반 전략전은 카메라의 각도를 정확히 56°, 수평 회전을 45°로 고정**합니다. 드래그·터치 및 메뉴의 시점 변경 기능이 사라져 지도의 X/Z 축 비율을 망가뜨리거나 멀미를 유발하지 않습니다. 실시간 본진 모드의 자유 카메라는 후속 기능으로 별도 구현할 예정이며 현재 제공하지 않습니다.
- **한 손가락/마우스 왼쪽 버튼으로 전장 아무 곳이나 누른 채 밀면 지도가 즉시 이동**합니다. 이전처럼 카메라가 회전하지 않습니다. 7 CSS px 이내의 가벼운 터치는 기존 부대·타일 선택으로 처리해 클릭과 이동을 분리합니다.
- 두 손가락 벌리기/오므리기 확대·축소 및 두 손가락 맵 이동, 마우스 휠 줌, +/− 버튼과 배율 슬라이더를 유지합니다. '⌂ 중앙으로' 버튼을 통해 지도를 초기 위치로 되돌릴 수 있습니다.
- 정사영 카메라의 가로세로 축척과 21×21 지도, 세 대학 4×4 캠퍼스, 기존 건물 및 게임 저장 키 v13은 그대로 유지합니다.
- 투영 보정 `dy/sin(56°)`을 적용해 손가락 이동에 반응하는 세계 좌표를 균일하게 맞춥니다. 시작 위치 기준으로 상대 위치를 계산하고 맵 경계에서만 이동을 제한하여 점진적인 흔들림과 튕김을 방지합니다.
- `fixed-camera-swipe-test.mjs`에서 각도 불변, 양방향 드래그의 투영 좌표, 경계 제약, 멀티터치 확대와 탭/드래그의 UI 분리를 검증합니다. 실제 모바일 실기기 UX는 검증하지 않았습니다.

## v1.8 — 영구 탐험 지도 (전장의 안개 개선)

- **미탐험 지역만 안개로 가립니다**. 성균관대의 정찰대, 보병과 확보한 거점이 한 번 밝혀 준 지형은 다시 어두워지지 않습니다. 기존 `state.explored.ally` 배열을 그대로 사용하므로 이전 v13 저장의 탐험 기록도 유지됩니다.
- 이전에는 현재 `visibleTiles()` 기준으로 지형을 숨기고, 전에 발견했던 지역을 옅은 안개로 덮었습니다. 이제 정적 지형·현대 도로·아파트·캠퍼스와 이미 발견한 자원은 `exploredTiles()`를 기준으로 계속 표시합니다. 타일 안개 인스턴스는 처음부터 방문하지 않은 칸에만 생성합니다.
- 적 부대의 **현재 위치/체력은 현재 시야에 들어왔을 때만** 표시되며, 이전에 탐험한 타일을 눌러도 숨은 적을 공개하지 않습니다. 공격 허용 기준은 그대로 현재 `visibleTiles()`입니다.
- 거점 깃발의 소유 색은 처음 발견한 이후 **마지막으로 직접 관측한 소유자**를 기억하고, 시야 밖에서 다른 팀이 점령하더라도 새 소유자가 자동 노출되지 않습니다. 다시 정찰하면 깃발과 표시 정보가 갱신됩니다. 과거 저장 파일의 미기록 거점 소유자는 임의 추정하지 않습니다.
- 기존 21×21 도시 지도, 4×4 캠퍼스, 고정 56° 아이소메트릭 카메라, 한 손가락 스와이프·핀치 조작, 저장 키 `campus-frontier-turn-v13` 및 게임 규칙은 유지합니다.
- `permanent-exploration-test.mjs`로 방문→이탈→소유자 변경→재방문→저장 불러오기를 검증합니다. 자동 검사는 실제 모바일 GPU 화면 검증을 대신하지 않습니다.

## v2.0 — 체스처럼 가볍게 즐기는 대학 라이벌 아레나

기본 랜딩 화면이 기존의 성대 캠퍼스 본진 관리가 아닌 **1:1 대전 허브**로 전환됩니다. 기존 Three.js 캠퍼스 지도와 3자전 전투는 상단 **기존 3D 전장**에서 필요할 때만 불러오도록 보존합니다. 신규 모드는 독립적인 9×9 턴 기반 2D 전략 보드 프로토타입으로, 3D 지도 전용 기능이 아직 이식된 것은 아닙니다.

### 바로 플레이 가능

- **PvE**: 대학 선택 → AI 상대와 9×9 단기전. 한 턴에 1행동(부대 이동, 인접 공격, 수비대/정찰대 모집 또는 대기). 중앙 3개 거점을 점유하면 별 수입 증가. 상대 캠퍼스 HP를 0으로 만들거나 24라운드 종료 시 점수로 승부.
- **PvP 친선전**: 같은 기기를 교대로 쓰는 2인 대전. 선택한 대학 양측의 병과/수입/체력은 동일하며 사전 통계로 특정 대학의 유불리를 주장하지 않습니다.
- **온라인 PvP 베타**: WebRTC 데이터 채널 연결 코드(offer·answer)를 서로 외부 채팅으로 복사·붙여넣어 직접 연결할 수 있습니다. 방장이 대전 상태를 검증해 전송하고 참가자는 자신의 차례에만 합법적인 행동을 보낼 수 있습니다. 연결 가능한 네트워크가 아니면 작동하지 않을 수 있습니다(STUN만 제공, TURN 릴레이 없음). 공용 대전 로비/자동 매칭/재접속은 아직 없습니다.
- **인게임 채팅**: 게임 옆에 실시간 대화창 추가. 직접 연결된 온라인 대전은 WebRTC 채널로 채팅을 보냅니다. 같은 기기 PvP는 로컬 대화 기록이며 PvE는 개인 메모(봇이 응답하지 않음)입니다. 160자 제한, 텍스트 안전 렌더링, 간단한 전송 속도 제한; 별도의 중앙 채팅 서버/신고/차단/모더레이션 기능은 미구현입니다.
- **랭킹/프로필**: 내 브라우저에만 저장하는 '연습 점수' 및 연습 등급, PvE 전적, 주 사용 대학. 대학별 '티어리스트'는 내 PvE 결과만으로 계산하며 학교당 3전 미만은 표본 부족으로 표시합니다. **공식 전 세계 등수, 실제 학교별 승률, 경쟁 ELO/MMR은 제공하지 않습니다.** PvP 친선전은 조작 가능한 클라이언트 결과이므로 공식 레이팅에 반영하지 않습니다.

### 서버 운영으로 전환할 때

검증된 계정(인증), 서버 권위 게임 상태/행동 검증, 매칭 큐, 레이팅(ELO/Glicko), 서버 저장 경기 로그와 부정 방지, 대화 신고/차단/모더레이션, 시즌별 대학 티어 집계 및 실사용 통계가 필요합니다. GitHub Pages는 정적 파일 배포만 제공하므로 이것들은 호스팅된 서버·DB 연결 없이 안전하게 구현했다고 주장할 수 없습니다. 현재 WebRTC는 외부 채팅으로 연결 코드를 교환하는 **1대1 친선 베타**입니다.

신규 모듈: `arena-engine.js`, `arena-peer.js`, `arena-ranking.js`, `arena-app.js`, `arena.css`. 테스트: `arena-test.mjs`가 초기 대칭성·합법 행동·AI·거점·승패·연습 랭킹·PvP 비공식성·UI 연결 및 기존 3D 모드 보존을 검증합니다.

기존 v13 전략전 저장과 v1.8 영구 탐험 기록은 건드리지 않습니다.
