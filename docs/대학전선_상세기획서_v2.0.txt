이 문서는 기본 규칙의 모호함을 줄이기 위해 이전 제안을 수정한다. 충돌 시 본 문서의 명시 규칙을 우선하고, 미정 항목은 마지막 목록을 따른다.

01. 비전과 범위
==================================================

1.1. 한 문장 소개
실제 대학 캠퍼스 전체를 축소한 지상형 본진을 중심으로 탐험·연구·경제·외교·전쟁을 연결하고, 대학별 고유 운영과 연합을 통해 승리하는 3D 동시 턴제 전략게임.

1.2. 핵심 경험
① 전체 학교를 발견하고 알아보는 즐거움.
② 제한된 운영력으로 확장·연구 기반·군사 중 투자 순서를 선택하는 재미.
③ 상대 명령을 모른 채 이동과 공격을 계획하는 심리전.
④ 대학마다 달라지는 성장 루프와 대응법.
⑤ 강해진 세력이 주변 대학의 외교를 바꾸는 전황.

1.3. 기획 원칙
- 확보 자료 범위의 전체 건물 배치를 유지한다. 대표 건물 몇 동으로 축약하지 않는다.
- 3×3은 캠퍼스 점유 타일 수이지 건물 수가 아니다.
- 캠퍼스는 외부 도로·지형과 이어진 본진이며 공중 장식물이 아니다.
- 기본 게임은 한 지도에서 진행된다. 전투마다 별도 전장으로 로딩하지 않는다.
- 30분 공통 업데이트를 기다리지 않는다. 싱글은 준비 즉시 다음 턴으로 간다.
- 한 대학이 모든 분야에서 유리하지 않는다. 강점은 비용·조건·대응법을 가진다.
- 영구 성장 능력치가 기본 경쟁전의 시작 우위가 되지 않는다.
- 시각적 실제성과 게임 규칙의 공정성을 구분한다.

1.4. 기본 대전 사양
참가: 대학 3개, 초기 싱글은 플레이어 1 + AI 2.
지도: 21×21 정사각 타일, 좌표 x/y는 0~20.
본진: 대학당 3×3, 시작부터 위치 고정.
기간: 최대 30턴.
시간: 30~45분 목표 가설. 처리·사고 시간이 길면 실제 목표를 수정한다.
시점: 사선 3D, 회전·확대, 기본 시점 복귀.
플랫폼: PC 웹 우선. 모바일은 UI 후속 대응.
진행: 명령 계획 → 잠금 → 동시 처리 → 결과 → 다음 턴.

1.5. 용어
라운드/턴: 모든 대학의 한 번의 계획과 실행을 합친 단위. 문서에서는 턴으로 통일.
운영력: 누적 재화. 표기 약어 OP.
연구력: 선택 기술에 매 턴 투자되는 산출. 표기 RP.
거점: 외부 확장 중심. 캠퍼스와 구별.
시설: 타일에 설치하는 건설물.
대학 특성: 특정 진영의 창작 규칙.
주명령: 부대당 한 턴에 하나 선택하는 행동.

02. 한 판과 장기 성장
==================================================

2.1. 시작 상태
각 진영: 캠퍼스 1, 보병 1, 정찰대 1, OP 10, 부대 상한 6.
캠퍼스 기본 산출: OP 5/턴, RP 3/턴.
1턴에는 시작 자원만 주며 기본 수입을 중복 지급하지 않는다. 2턴부터 턴 시작에 수입을 받는다.
모든 진영은 초기 시야와 시작 근처 성장 기회를 동등한 기준으로 받는다.

2.2. 판 내 성장
영토·시설·기술·병력·대학 고유 자원은 판 안에서만 유지된다. 새 대전은 기본 조건으로 시작한다. 각 대학의 외형은 선택 가능하되 전투 판정은 동일하다.

2.3. 판 밖 유지
전적·도감·업적·캠퍼스 장식·시나리오 해금·외형 보상만 유지한다. 처음에는 대학 선택을 유료나 긴 노가다로 막지 않는다. 실제 재학 인증도 필수가 아니다.

2.4. 기본 루프
탐험 → 첫 거점 점령 → 자원 개발 → 연구·생산 선택 → 타 대학 접촉 → 중앙 목표 경쟁 → 외교/전쟁 → 승리.
반복 전투로 영구 공격력을 쌓는 습격 육성형 구조는 기본 모드에서 제외한다. 비동기 방어전은 나중에 별도 규칙으로 만든다.

03. 지도·캠퍼스·영토
==================================================

3.1. 캠퍼스 구현
원본 건물의 상대적 위치·도로·주요 지형을 유지한다. 가로세로 비율을 유지해 3×3에 맞추며 남는 공간은 녹지로 처리한다. 앞선 대화의 성대 건물 56개 수치는 원본 검증 전 참고값이다. 실제 포함 건물 수·누락·높이값·권리 조건을 목록화한다.
개별 건물은 장식/정보 대상이며 각각 생산·체력 시스템을 갖지 않는다. 캠퍼스 전체가 내구도 30을 공유한다. 건물을 철거해 유리한 통로를 만드는 행동은 없다.

3.2. 이동과 본진 공격 접점
캠퍼스 3×3 내부는 일반 이동 불가. 각 변 중앙 바깥의 네 타일을 본진 접점으로 표시한다. 이 네 타일 중 최소 둘은 시작 지형에서 접근 가능해야 한다. 정문 외형의 위치와 전투 접점은 별도 개념이다.
인접 공격 부대는 접점에 서서 본진을 공격한다. 원거리 부대도 네 접점 중 하나까지의 거리가 사거리 이내이고 접점을 볼 수 있어야 한다. 코너만 접한 위치에서 본진 공격은 불가.
출전 타일은 자기 본진 접점 중 빈 곳을 선택한다. 출입구 봉쇄를 피하도록 본진 접점에는 성벽·탑을 설치할 수 없다. 도로는 허용한다.

3.3. 지형과 거리
이동은 상하좌우 4방향. 거리·시야·사거리는 맨해튼 거리 사용.
평지: 진입 비용 1, 엄폐 0.
숲: 진입 비용 2, 엄폐 1.
언덕: 진입 비용 2, 엄폐 0, 점유 부대 시야 +1.
물: 초기 통행 불가. 해전은 제외.
도로: 연결 도로 두 칸 이동을 하나의 이동 단계로 처리하는 특수 규칙은 초기 제외. 도로는 기본 진입 비용을 1로 낮추는 효과만 갖는다.
부대는 1턴 이동력만큼 비용을 지불한다. 이동력이 1인 부대도 비용 2 지형에 인접한 경우 그 지형으로 한 칸 진입하고 턴을 끝낼 수 있다. 이를 '험지 진입'으로 UI에 표시한다.
시야를 언덕이 보조하지만 초기에 지형에 의한 선형 사격 차단은 적용하지 않는다. 보이는 타일이면 거리로 공격 가능하다.

3.4. 영토
캠퍼스는 3×3과 외곽 한 칸의 링을 초기 영토로 가진다. 지도 밖 영역은 제외.
거점은 자신과 상하좌우 거리 1 이내 타일을 편입한다.
중복 영토는 기존 소유 우선. 거점으로 신규 편입한 타일에 소유 근거 거점 ID를 기록한다. 거점 점령 시 그 타일 묶음이 이동하며 다른 근거의 영토는 자동 이전하지 않는다. 캠퍼스 초기 영토는 거점으로 빼앗지 못한다.
초기에는 타일 구매·문화 확장·영토 행복도 없음.

3.5. 맵 구성
기본 지도: 중립 일반 거점 6개 + 중앙 주요 거점 1개, 총 7개를 시작값으로 한다.
각 대학은 초기 근처 일반 거점 1개, 그보다 먼 경쟁 후보 1개에 접근할 기회를 가진다.
캠퍼스 영역끼리 겹치지 않고, 첫 거점까지의 거리와 자원 기대값을 비교한다. 중앙 목표로 가는 길이 하나의 영구 봉쇄점만 통과하지 않게 한다.
처음에는 수동 제작한 검증 맵을 사용한다. 무작위 생성은 기본 규칙 완성 후 도입한다. 세 진영 완전 대칭이 어려우므로 시작 위치 교대 테스트를 실시한다.
4×4 본진·서울 실측 위치는 별도 확장 맵으로 보류한다.

04. 자원·수입·생산
==================================================

4.1. OP 수입
캠퍼스 5, 일반 거점 2, 중앙 거점 2, 경제 특화 추가 2, 개발 자원 타일 1.
완공·점령한 턴에는 추가 수입을 소급 지급하지 않는다. 다음 턴 시작부터 적용.
부대 유지비는 첫 버전 제외. OP 상한도 초기 없음.

4.2. RP
캠퍼스 3, 연구 특화 거점 2, 연구 시설 1.
매 턴 종료 시 이번 턴 시작 상태에서 확정한 RP 산출을 연구에 투자한다. 그 턴 본진/시설을 잃었더라도 이미 확정된 연구 생산은 적용한다. 탈락 진영은 예외로 연구 완료를 처리하지 않는다.
연구 미선택 RP는 최대 10 보관. 상한 초과분은 소실하므로 UI 경고. 연구 선택 시 보관분과 해당 턴 RP를 함께 투자.
기술당 한 턴 한 개만 완료. 초과 RP는 최대 10 보관. 다음 기술로 같은 턴 연속 완료하지 않는다.

4.3. 예약 비용
계획 중 비용을 임시 보류한다. 취소 시 전액 해제. 명령 잠금 때 유효한 예약의 실제 비용을 차감한다. 검증 실패는 비용을 차감하지 않는다.
잠금 뒤 진행 중인 작업이 실패하면 항목별 환급 규칙을 따른다. 무효와 전투 방해 실패는 UI에서 구분한다.

4.4. 생산 슬롯
캠퍼스와 각 안정화 완료 거점에 작업 슬롯 1개. 병력 모집·거점 특화·시설 건설·시설 수리를 공유한다. 연구는 별도 슬롯.
한 작업장은 한 턴에 새 작업 하나만 시작할 수 있다. 완료 후 같은 턴 추가 생산 불가.
시설은 그 시설이 속한 작업장의 영토에만 예약한다. 생산 시간을 단축하는 효과는 최소 1턴.

4.5. 부대 상한
6 + 정상 거점 수, 최대 10. 중앙 거점도 한 개로 계산.
예약 모집까지 포함해 상한을 검사한다. 거점 상실로 상한 초과 시 기존 병력을 삭제하지 않고 모집을 중단한다. 진행 모집은 대기 상태로 두며 상한 회복 후 재개한다.
모집 완성 시 지정 출전 칸이 막히면 완성 대기. 슬롯 점유 유지, 다음 턴 다른 유효 칸 지정 가능. 한 번도 배치되지 않은 모집 취소는 OP 50% 환급(소수점 버림).

05. 거점·점령·개발
==================================================

5.1. 점령
보병·정찰대·기동대 가능. 공성대는 점령 불가.
거점 위에 서서 점령 주명령을 선택한다. 이동과 같은 턴 불가. 턴 종료 시 생존하고 자기 진영이 거점 타일을 점유하면 성공한다. 피해를 입어도 생존하면 중단되지 않는다.
적 부대가 거점을 점유 중이면 점령 예약 불가. 적 제거 후 다음 턴 진입, 이후 점령해야 한다. 점령 유지 중 적에게 타일을 빼앗기면 실패.

5.2. 안정화
중립 거점: 점령 후 다음 턴 시작부터 정상 작동.
적 거점: 점령 다음 턴을 안정화에 사용. 그 다음 턴부터 수입·생산·상한 적용. 예: 8턴 점령, 9턴 안정화, 10턴 정상.
점령 이전 진행 중인 작업은 취소. 이전 소유자에게 미완료 작업 비용 50% 환급. 완성 시설은 보존하되 파괴된 시설은 복원되지 않는다.

5.3. 특화
정상 일반 거점에 OP 6, 작업 1턴. 경제(+2 OP), 연구(+2 RP), 군사(병력 모집 -1턴) 중 하나.
초기에는 변경 불가. 중앙 거점은 특화 불가.
거점 특화는 점령 후에도 유지하되 안정화 이후 적용한다.

5.4. 자원 개발
자원은 초기 모두 '개발 자원' 하나로 통일한다. 대학별 현실 이미지와 특정 자원을 억지로 연결하지 않는다.
자원 개발 기술 + 자기 영토 + 빈 작업 슬롯, OP 3, 1턴 필요. 완료 후 +1 OP/턴. 자원 타일은 한 시설 레이어만 사용하므로 방어탑과 동시 설치 불가. 도로는 별도 레이어로 허용.

06. 연구 트리
==================================================

6.1. 공통 12개
개척: 자원 개발(6, 선행 없음) → 거점 전문화(10) → 광역 관리(16).
군사: 조직 훈련(6, 없음) → 공성 기술(12), 기동 전술(16).
기반: 방어 건축(6, 없음) → 도로망(10), 방어 체계(16).
학술: 연구 방법(8, 없음) → 전문 연구(14) → 종합 프로젝트(20).

6.2. 해금
자원 개발: 자원 타일 개선.
거점 전문화: 경제/연구/군사 특화。
광역 관리: 일반 거점 한 곳을 지정하여 영토를 거리 2까지 확장. 기존 소유 타일 침범 불가. 이후 지정 변경 불가.
조직 훈련: 방어 명령의 방어 보정 +1 추가.
공성 기술: 공성대 모집.
기동 전술: 기동대 모집.
방어 건축: 성벽.
도로망: 도로. 모든 진영은 완성된 도로의 이동 비용 효과를 이용할 수 있다.
방어 체계: 방어탑.
연구 방법: 연구 시설.
전문 연구: 대학별 두 계통 중 하나 선택.
종합 프로젝트: 지식·경제·방어 중 상징 과제 하나 착수 가능. 최초 판은 대학별 다른 프로젝트 없이 공통 과제를 사용.

6.3. 프로젝트
OP 15, 캠퍼스 작업 슬롯 3턴, 완료 10점. 캠퍼스당 한 번만 완료. 완성 즉시 승리는 아님.
캠퍼스가 공격받아도 작업은 진행되지만 함락 시 취소. 병력 모집과 슬롯을 공유해 기회비용을 만든다.

6.4. 연구 변경
계획 단계에 다른 기술로 변경 가능. 기술별 누적 RP는 보존한다. 변경 비용 없음. 이미 완료된 기술은 재연구 불가. 할인은 해당 기술에 기록해 중복 적용하지 않는다.

07. 부대·전투 수치
==================================================

7.1. 초기 수치
병과 / HP / 공격 / 방어 / 이동 / 사거리 / OP / 모집 턴
보병 / 10 / 4 / 2 / 1 / 1 / 5 / 1
정찰대 / 7 / 2 / 1 / 2 / 1 / 4 / 1
공성대 / 8 / 3 / 1 / 1 / 2 / 9 / 2
기동대 / 9 / 4 / 1 / 2 / 1 / 8 / 2
보병·정찰은 시작부터, 나머지는 연구 해금.
공성대는 시설·캠퍼스 대상 공격 +3. 정찰 시야 3, 나머지 2.

7.2. 행동
이동 / 공격 / 방어 / 점령 / 회복 / 대학 전술.
부대당 주명령 하나. 이동 후 자동 공격 없음. 이동 충돌로 생긴 교전은 예외.
방어: 해당 턴 방어 +1. 조직 훈련 후 총 +2.
회복: 자기 영토에서 이동·공격 없이 HP 2 회복. 적 피해를 받은 턴은 회복 취소. 회복은 공격 이후 처리한다. 최대 HP 초과 불가.
대기: 미명령 기본. 자동 공격·자동 방어 보정 없음.

7.3. 피해
max(1, 공격 + 대상별 보정 + 전술 보정 - 방어 - 엄폐 - 방어명령 보정).
체력 감소는 공격력을 낮추지 않는다. 무작위 치명타 없음. 피해는 공격 단계에서 일괄 적용. 유효한 공격자는 같은 단계에 전멸해도 공격한다.
일반 공격은 자동 반격을 발생시키지 않는다. 상대도 공격 명령을 냈거나 충돌 교전이면 서로 공격한다.
여러 적이 같은 대상을 공격하면 피해를 합산한다. 아군 피해는 없다.

7.4. 시야
현재 보이는 대상만 공격 예약 가능. 마지막 관측은 유령 표식으로 표시하고 현재 공격 대상으로 선택할 수 없다. 대상이 실행 시 시야/사거리 밖이면 실패. 시설·본진은 발견 후 위치는 기억하지만 공격 시 현재 시야는 필요하다.
초기 공개 시야 테스트 모드에서는 정보 특성 대신 테스트용 대체를 쓰지 않고 관련 대학 전술을 잠근다. 시야 구현 후 고유 능력 테스트를 진행한다.

08. 시설·건설
==================================================

시설 / OP / 턴 / 효과
자원 개발 / 3 / 1 / 해당 자원 OP +1
성벽 / 3 / 1 / HP 10, 방어 1, 지상 진입 차단
도로 / 타일당 1 / 1 / 도로 양끝 이동의 험지 비용을 1로
연구 시설 / 6 / 2 / 해당 거점 RP +1, 거점당 하나
방어탑 / 7 / 2 / HP 10, 방어 1, 공격 3, 사거리 2

8.1. 공통
소유 영토·해당 작업장 범위·빈 시설 칸 필요. 거점 중심과 캠퍼스 접점에는 성벽·탑 설치 불가. 적 점유 타일 건설 예약 불가. 아군이 있는 일반 타일에는 건설 가능하나 성벽 완공 때 아군이 남아 있으면 완공 대기.
도로는 시설과 별도 레이어. 연구 시설·자원 개발은 부대 이동을 막지 않는다. 성벽·탑은 부대가 점유하지 못하는 고정 장애물이다.

8.2. 방어탑
자기 소유 작업장이 안정화 중이면 공격 중단. 완공 다음 턴부터 자동 공격.
우선순위: 캠퍼스/거점에 인접한 적 → 가까운 적 → 현재 HP 낮은 적. 완전 동률이면 안정적인 개체 ID로 선택하며 UI에 현재 예상 대상을 표시. 적이 이동하면 대상이 바뀔 수 있음을 안내.
탑은 캠퍼스 주변 최대 2, 일반 거점 주변 최대 1. 중앙 거점 주변은 설치 불가.

8.3. 실패·철거·수리
턴 종료 건설 검증 때 타일을 잃었거나 적 부대가 점유하면 작업 취소, 원 비용 50% 환급. 작업장 자체가 함락돼도 동일.
기존 완성 시설은 즉시 자동 철거하지 않는다. 자기 시설 철거는 작업 슬롯 1턴, OP 환급 없음. 적이 남긴 시설도 소유 영토라면 철거 가능.
수리는 작업 슬롯·OP 2·1턴으로 HP 4 회복. 그 턴 시설이 피해를 받으면 회복하지 않고 비용 50% 환급. 무한 무료 복구를 피한다.

09. 턴 처리와 예외
==================================================

9.1. 계획 시작
수입과 시야 확정 → 연구/생산 상태 표시 → 각 명령 예약 → 경고 → 준비 완료.
AI는 플레이어의 비공개 명령을 보지 않는다. 동일한 관측 상태와 자체 목표로 계획한다.
싱글은 시간 제한 없음. PvP는 우선 60초 가설, 전원 준비 시 조기 처리. 시간 초과는 유효 예약만 유지하고 나머지는 대기.

9.2. 실행 순서
1) 명령 잠금, 비용·소유권·선행 조건 재검증과 유효 비용 차감.
2) 방어·사전 대학 전술 적용.
3) 이동을 단계별 동시 해결, 충돌 그룹 확정.
4) 이동 뒤 시야 갱신, 일반 공격·충돌 공격·방어탑 공격 대상 확정.
5) 공격 피해 합산·동시 적용.
6) 전멸·시설 파괴·캠퍼스 함락 처리.
7) 회복·거점 점령 처리.
8) 생산·건설·연구 진행 및 완료. 탈락 진영 제외.
9) 프로젝트·목표·승리 점수 확인, 전투 기록 확정.
10) 다음 턴 진입·수입·RP 기준 산출 확정.
캠퍼스 함락이 연구 완료보다 먼저이므로 그 턴 완성 예정 연구로 패배를 되돌릴 수 없다.

9.3. 이동 충돌 세부
아군 동일 목적지: 계획 단계 불가. 아군 자리를 통과하려면 해당 부대도 그 칸을 떠나야 한다.
아군 순환 이동(A→B→C→A): 모두 이동 가능한 경우 허용.
적대 부대가 같은 빈 타일 진입: 진입 취소, 출발점 유지, 조우 충돌 관계 등록.
적대 자리 교환: 통과 취소, 경계 충돌 등록.
적 점유 타일 돌입: 적이 머물면 진입 취소·충돌 등록. 적이 다른 유효 칸으로 떠나면 진입 가능. 자리 교환은 별도 충돌 규칙 우선.
여러 진영이 한 타일로 진입: 모두 정지, 해당 이동 단계에서 출발 위치 기준 서로 가장 가까운 적 하나를 충돌 공격 대상으로 지정. 동률은 개체 ID. 각 부대는 최대 한 번만 공격.
한 이동 단계 충돌 부대는 남은 이동을 포기한다. 모든 경로는 이동력 최대 2를 우선 지원한다.
앞선 문서의 '조우전 승자가 즉시 목적지 진입'은 제거한다. 전투 후 이동은 없으며 다음 턴 직접 진입한다. 이 변경으로 연쇄 진입 예외를 줄인다.

9.4. 합성 공격 중복 방지
이동 명령 부대는 충돌했을 때만 기본 공격한다. 일반 공격 명령과 충돌 공격을 한 부대가 동시에 수행하지 않는다. 충돌 상대가 공격 전에 다른 사건으로 사라지면 공격 취소. 충돌 공격은 해당 충돌 관계에 한해 현재 타일 거리 제한 예외를 허용하고 UI에 근접 조우전으로 표시한다.

9.5. 대표 예외
- 공격 대상 사거리 이탈: 공격 실패, 다른 적 자동 선택 없음.
- 두 부대 동시 전멸: 모두 제거.
- 거점 점령자 전멸: 점령 실패.
- 이번 턴 완성 탑: 이번 턴 공격 안 함.
- 이번 턴 연구 완료: 다음 턴 모집/건설에 사용.
- 모집 출구 차단: 완성 대기.
- 같은 대상에 과잉 피해: 초과 피해 이전 없음.
- 캠퍼스 동시 함락: 아래 승리 규칙 적용.
- 네트워크 재전송: 같은 명령 ID는 한 번만 처리.

10. 대학별 문명식 기믹
==================================================

10.1. 공통 구성
대학당 기본 능력 1 + 전문 연구 2분기 + 고유 전술 1~2 + 외형 테마.
별도 고유 자원은 필요할 때만 사용한다. 이익을 얻는 행동·소모처·상한·상대 대응이 모두 있어야 한다. 모든 대학은 공통 기술과 기본 병과를 사용한다.
학문·연결·결집 등의 명칭은 게임 내 창작 표현이다.

10.2. 성균관대: 학문의 축적
방향: 폭넓은 기초 연구에서 필요한 전문 기술로 연결.
기본 능력: 서로 다른 공통 기술 3개 완료마다 학문 1. 12개 공통 기술에서 최대 4 획득. 고유 분기는 횟수에 포함하지 않는다.
학문 상한 3. 새 연구를 선택할 때 1을 사용해 그 기술 총 비용 -3, 최소 비용 3. 기술당 한 번, 취소/재선택으로 중복 불가. 진행 중 기술에도 한 번 적용 가능. 할인 뒤 이미 투자가 충분하면 다음 종료 단계에 완성한다.
전문 연구 완료 후 분기 선택:
공학 — '긴급 보수': OP 2, 캠퍼스/거점 작업 슬롯을 소모하지 않고 지정 시설 HP 3 회복. 전투 후 처리, 그 턴 피해를 받으면 취소·OP 환급. 3턴 재사용 대기.
정보 — '학술 관측': OP 2, 관측 구역 중심 거리 2 시야를 실행 단계 시작부터 턴 종료까지 확보. 3턴 재사용 대기. 상대 예약 명령을 공개하지 않는다.
분기는 판 중 변경 불가. 능력이 연구 선택지를 늘리되 모든 기술을 즉시 완성하지 않게 한다.
약점: 연구 기반 투자로 즉시 병력이 부족할 수 있다. 확장 거점이 차단되면 생산과 전문 기술 운용 비용이 부담.
외형: 전체 실제 캠퍼스 배치, 전통·현대 건축 대비, 연구 표식은 관리 화면 중심.

10.3. 연세대: 연결망
방향: 캠퍼스·거점을 연결하고 여러 부대의 유지력을 보조.
기본 능력: 자기 소유 도로로 캠퍼스와 이어진 정상 거점의 거리 1 이내 아군 회복량 +1. 중첩 없음. 도로망 해금 전에는 연결 능력이 비활성임을 안내.
연결 판정: 상하좌우 연속 도로, 자기 영토만 인정. 적 부대가 점유한 도로 타일에서 연결 단절. 중립 부대도 점유 시 단절. 시야 공유와 자동 동맹은 별개.
전문 분기:
지원 — 연결 거점 주변 아군의 회복이 피해를 받지 않은 경우 +1 추가(기본 2+능력1+전문화1).
교류 — 연결 거점 최대 두 곳에서 각각 OP +1. 지정 거점은 계획 단계에 변경, 다음 턴 적용.
고유 전술은 두 번째 구현 단계에서 추가. 초기 연결·분기만으로 테스트한다.
약점: 도로 투자와 연결 유지 필요. 중간 지점 침투에 취약.
외형: 과도한 연결선 대신 선택 시 보급선을 표시, 깃발·조경 포인트로 식별.

10.4. 고려대: 결집과 돌파
방향: 공세를 준비하고 시설·요충지에 힘을 집중.
기본 능력: 하나의 집결 표식을 자기 영토에 지정. 주변 거리 1 이내 자기 부대 2개 이상이 한 턴을 마치면 결의 +1, 최대 2.
충전 제한: 한 번 충전한 뒤 적과 교전하거나 새 중립/적 거점을 점령해야 충전 자격 회복. 방어탑 공격만 받는 것으로는 회복하지 않는다. 첫 충전은 시작부터 가능.
사용: 결의 1로 이번 턴 지정 부대 최대 2의 시설/본진 공격 +1. 일반 부대 피해에는 적용하지 않는다.
전문 분기:
돌파 — 결의 효과 대상에 공성대가 포함되면 그 공성대 시설 피해 추가 +1.
재집결 — 결의를 사용한 다음 턴 지정 부대 하나가 회복할 때 회복량 +1.
약점: 집중 방향 반대의 거점이 비며, 결의만으로 적 보병을 지울 수 없다.
외형: 집결 깃발·공세 방향 화살표, 실제 건물을 전투 테마로 교체하지 않는다.

10.5. 서강대: 집중 운용
방향: 제한된 핵심 부대의 정보·위치를 정밀하게 관리.
기본 능력: 시작 부대 두 개를 정예로 지정. 정예는 방어 명령 중 시야 +1. 전멸 시 3턴 후 자기 부대 하나에 재지정 가능. 두 슬롯을 따로 관리.
전문 분기:
기동 — 정예 한 개와 인접 아군의 위치 교환 허용. 두 부대 모두 주명령을 소비, 적 점유·성벽 통과 불가. 대학당 2턴 재사용 대기.
정찰 — 정예 시야 상시 +1로 변경. 방어 시야와 중첩하지 않는다.
위치 교환은 계획 단계에 확정하며 적 명령을 본 뒤 바꾸는 능력이 아니다.
약점: 여러 거점을 동시에 지키기 어렵고 정예 손실 후 공백이 발생한다.
외형: 정예 표식과 정돈된 이동 궤적. 실제 캠퍼스 크기를 비하·과장하는 설정은 쓰지 않는다.

10.6. 한양대: 현장 설계
방향: 시설 개조 또는 공성 준비를 미리 선택.
기본 능력: 시작 시 방어 설계(성벽 HP +2) 또는 공성 설계(공성대 OP -1) 선택. 판 중 기본 설계 변경 불가.
전문 분기:
구축 — 시설 수리 회복량 +2. 피격 시 수리 취소 규칙은 동일.
공성 — 공성대 생산 1턴 감소, 최소 1턴. 군사 거점과 중첩해 0턴이 되지 않는다.
시설 개조 전술은 후속 콘텐츠로 보류. 초기에는 생산과 수리 차이를 먼저 검증한다.
약점: 준비 전 압박과 전선 이동. 설계가 모든 병과의 능력을 높이지 않는다.
외형: 개조 표식·작업 표시, 전체 캠퍼스를 공장으로 재해석하지 않는다.

10.7. 대학 구현 순서
1차 성대 기본 능력 → 2차 고려대 기본 능력 → 공통 연구/시야 안정화 → 성대 전문 분기 → 다른 대학 순차.
다섯 대학을 첫 실행 버전에 모두 넣지 않는다. 데이터 구조는 추가 가능하도록 준비한다.

11. AI·외교·연합
==================================================

11.1. AI 정보와 목표
AI는 공개 지도와 자기 시야, 발견한 적 정보만 사용한다. 플레이어의 예약 명령·미관측 병력·미발견 자원을 읽지 않는다.
평가 항목: 생존 위험, 거점 가치, 경제/연구 투자, 전선 거리, 외교 관계, 대학 특성.
난이도 '기본'은 자원 보너스 없음. 상위 난이도 추가 산출을 넣으면 시작 화면에 수치를 명시한다. 초기에는 난이도 하나만 구현.

11.2. 상태
미접촉: 서로 발견 전. 발견 후 중립.
중립: 공격·적 거점 진입은 가능하나 명시 경고 후 전쟁 선언과 묶여 예약된다.
전쟁: 공격·점령 가능.
휴전: 5턴, 공격·적 영토 진입 금지. 초기에는 중도 파기 불가.
공동전선: 공통 상대·기간·허용 협력을 표시. 초기 시야 공유는 선택 조항이며 자원/병력 공유는 없음.
모든 합의는 양측 수락 후 다음 턴 시작 적용. 실행 중 갑자기 명령을 무효화하지 않는다.

11.3. 휴전 시 영토 안 부대
합의 단계에서 상대 영토에 있는 부대가 있으면 휴전 시작과 동시에 가장 가까운 합법 중립/자기 타일로 이동. 동률은 x, y 순. 도달 타일이 없으면 합의 적용을 보류하고 이유를 알린다. 무상 탈출 악용과 복잡도를 줄이기 위해 초기 UI는 상대 영토 내부 부대가 있으면 휴전 제안 자체를 제한하는 단순 구현을 먼저 사용해도 된다. 이 경우 양측 화면에 명시한다.

11.4. 강자 견제
개인에게 외부 병력을 갑자기 생성하는 대신 지도에 존재하는 대학이 공동 대응한다.
평가: 점수 격차·거점 비중·병력 위협·최근 공격·자신의 이해관계. 선두라는 이유만으로 자동 증오하지 않는다.
예고: '주변 대학이 확장을 경계함' → 접촉/협상 → 공동전선 결성 → 공세 방향 관측.
공격 역할: 견제군, 거점 기동군, 공성군. 병력이 실제 생산돼 이동해야 한다.
플레이어가 약자라면 AI가 협력을 제안할 수 있다. 연속 패배한 플레이어에게 숨겨진 반복 처벌을 주지 않는다.

11.5. 이벤트 이름
연고전: 연세대와 고려대가 서로 경쟁하는 특별 시나리오.
연고 공동대응: 두 대학이 공통 상대를 견제하는 별도 창작 이벤트.
서성한 공동전선: 소속에 따라 협력 또는 상대 연합. 자기 대학을 이유 없이 적군에 포함하지 않는다.
3인 기본 대전에서 불가능한 조합은 억지로 생성하지 않는다. 서성한과 외부 강자가 함께 나오는 이벤트는 4인 이상 별도 맵에서 구현한다.
실제 플레이어 연합은 수락으로만 성립한다. 시스템이 강제로 공격시키지 않는다.

12. 승리·탈락·점수
==================================================

12.1. 본진
HP 30, 기본 방어 0, 자동 반격 없음. 외곽 시설과 부대가 방어를 맡는다. 본진 공격과 일반 시설 공격은 같은 공격 단계. 실제 학교 건물이 무너지는 표현 대신 내구도·깃발·경고선 사용.

12.2. 함락
HP 0 캠퍼스의 대학은 그 턴 탈락. 그 진영 부대 제거, 일반 거점 중립화, 진행 작업 취소. 탈락자 환급은 계산하더라도 더 이상 사용 불가.
캠퍼스는 지도에 잔존한 비활성 점령지로 남고 부대 통과는 계속 불가. 적 대학 고유 능력 획득 없음.
본진 장악 기록은 그 턴 본진에 가장 많은 유효 피해를 준 생존 대학에 귀속. 동률이면 공동 장악으로 간주해 장악 점수 10을 동률 진영 수로 나눈다(소수 허용). 탈락한 공격자는 장악 점수를 받지 않는다.

12.3. 승리
실행 후 대학 하나만 생존하면 즉시 패권 승리.
30턴 종료 때 둘 이상 생존하면 점수 승리.
모든 대학이 같은 턴 탈락하면 공동 패배/무승부로 기록. 마지막까지 남았다는 가상의 순서를 만들지 않는다.

12.4. 점수
정상 일반 거점 개당 3.
중앙 주요 거점은 총 5(일반 3과 중복 아님).
완료 공통 기술 개당 2.
종합 프로젝트 완료 10.
자기 캠퍼스 생존 5.
적 캠퍼스 장악 지분 총 10.
탈락 대학은 최종 승리 후보에서 제외하고 달성 점수는 전적에만 남긴다.
동점: 자기 캠퍼스 HP → 정상 거점 수 → 완료 연구 수 → 공동 승리.
점수는 매 턴 확인 가능하되 미관측 적의 개별 산출을 역추론하지 않도록 초기에는 총점만 공개. 기여 상세는 판 종료 후 전체 공개.

13. 게임 모드
==================================================

싱글 기본전: 3대학, 최대 30턴, 저장 가능.
연습전: 공개 시야, 짧은 지도, 규칙 확인. 전적/시즌 점수 없음.
시나리오: 10~15턴 목표, 방어·호위·돌파 등, 5~15분 목표 가설.
실시간 친선: 기본전과 같은 규칙, 명령 제한시간, 서버 판정. 기본전 안정화 뒤.
경쟁전: 규칙·대학·맵 균형 검증 후 도입. 시즌 보상은 외형/기록 중심.
협동전: 별도 4인 지도에서 2플레이어 대 AI 연합. 후속.
비동기 습격: 저장 방어 AI 상대. 기본 문명형 모드와 성장/손실 규칙이 다르므로 초기 제외.
대규모 대학 시즌: 장기 공동 지도·영향력·기여도. 기본전과 별도 확장안이며 본 문서 구현 범위 아님.

14.2. 지도 선택
타일 클릭: 지형·소유·시설 표시.
아군 클릭: 이동 범위·사거리·행동.
적 클릭: 관측 정보와 예상 피해. 미확인 능력치에 확정 수치인 듯 표시하지 않는다.
캠퍼스 클릭: 본진 HP·생산·대학 능력·확대.
거점 클릭: 산출·특화·안정화·작업.
선택 해제와 카메라 복귀를 항상 제공한다.

14.3. 예약 표시
이동=화살표, 공격=대상선, 건설=반투명 모형, 점령=깃발, 회복=별도 아이콘.
선택 예약은 강조하고 나머지는 연하게. 아군 경로가 겹치면 경고와 수정 대상 이동 버튼.
사용 가능 OP와 보류 OP를 나눠 표시. '비용 부족/기술 부족/영토 밖/슬롯 사용 중/지형 부적합'을 다른 이유 문구로 표시한다.

14.4. 턴 종료 경고
미명령 부대, 연구 없음, 빈 주요 생산 슬롯, 충돌 예약. 한 번에 요약하고 그대로 종료 가능. 경고별 끄기 지원.
최초 3턴은 미명령 경고를 강조하지만 모든 턴 강제 확인창을 띄우지 않는다.

14.5. 연구 화면
좌 계통, 중앙 노드, 우 효과·비용·선행, 하단 현재 연구. '해금됨/선택 중/완료/불가'를 색+아이콘+문구로 표시. 대학 전문 분기 선택은 되돌릴 수 없으므로 첫 선택 때 확인.

14.6. 외교 화면
상대 대학, 관계 기간, 현재 제안, 알려진 이해관계. 합의 효과·시작 턴·종료 턴을 숫자로 표시. AI 감정을 사실처럼 과도하게 상세 공개하지 않고 관측 가능한 태도 수준으로 표현.

14.7. PC 조작
좌클릭 선택, 행동 버튼으로 모드 진입 후 타일 클릭 확정. 우클릭 취소(선택적). Esc 이전 단계. Space/Enter 턴 종료는 첫 버전 기본 비활성 또는 확인 필요. WASD/가장자리 이동은 옵션. 휠 줌, 회전 버튼/드래그. 단축키 도움말 제공.

14.8. 모바일 후속
하단 행동 바와 접이식 정보 시트, 두 손가락 확대/회전. 지도 탭만으로 즉시 턴 종료하지 않는다. 마우스 우클릭 전용 필수 기능 없음. 필수 터치 영역과 글자 크기는 실제 기기 테스트 후 수치 확정.

15. 3D 미니어처 화면
==================================================

15.1. 화면 목표
학교 전체를 보는 만족과 전략 가독성을 동시에 확보. 건물은 사실적 배치, 재질은 단순하게. 부대·시설은 실제 축척보다 과장해 읽기 쉽게 한다.

15.2. 레이어
배경 도시 실루엣 → 공통 지면/도로 → 캠퍼스 건물·식생 → 전략 시설 → 병력 → 정보 표식.
캠퍼스 축소율, 타일 크기, 부대 크기는 독립 파라미터. 전체 캠퍼스를 실물 축척으로 맞춰 부대가 보이지 않는 상황을 피한다.

15.3. 카메라
사선 하향 약 40~50도 범위를 테스트. 직교와 약한 원근 비교 후 선택. 기본 북쪽 표시·90도 회전 버튼·원위치 복귀.
전략 줌: 거점/부대 아이콘, 건물 이름 숨김.
전술 줌: 타일·시설·부대·예상 효과.
감상 줌: 전체 건물·이름·도로, 전투 오버레이 최소화.
감상 줌은 다른 게임 모드가 아니며 시간 정지나 별도 내부 전장을 만들지 않는다. 온라인에서는 카메라 확대 중에도 제한시간 진행.

15.4. 지면 연결
단차를 자연스럽게 연결하되 실제 지형과 전략 타일이 다를 경우 시각 혼란을 줄이는 경계 표시를 둔다. 떠 있는 두꺼운 판·검은 받침대 없음. 게임용 외곽 방어권과 실제 캠퍼스 자료의 경계는 녹지/길로 자연스럽게 전환.

15.5. 색·가림·피해
자연 건물색 유지, 진영색은 깃발·테두리·시설 포인트. 빨강/초록만으로 아군/적을 구분하지 않는다. 가린 부대는 실루엣 아이콘, 필요 시 해당 건물만 일시 투명. 실제 건물 위치·높이를 읽기 좋게 영구 왜곡하지 않는다.
본진 피해는 깃발·경고선·HP 변화. 폭력적 실제 학교 파괴 연출을 기본 톤으로 삼지 않는다.

15.6. 연출과 사운드
이동·공격·점령을 설명 순서로 재생하되 실제 동시 판정과 혼동하지 않게 '턴 결과 재생' 표시. 배속·건너뛰기·로그 제공. 잦은 원거리 전투는 카메라 이동을 축소한다.
캠퍼스 차분한 음악, 전황 긴장도 변화. 실제 교가·음원은 허가 확인 전 사용하지 않는다. 화면 흔들림·점멸 옵션 제공.

16. 첫 10턴 튜토리얼
==================================================

16.1. 교육용 고정 맵
정찰 시작점에서 첫 2턴 내 자원 발견, 보병 시작점에서 일반 거점까지 평지 3칸 경로. 적은 8턴 이전 캠퍼스 급습을 하지 않도록 이 시나리오의 행동 목표를 제한한다. 일반 AI에 숨은 보호를 그대로 넣지 않는다.
기술 순서: 자원 개발 → 조직 훈련 → 거점 전문화. 강제는 처음 두 선택까지만, 이후 추천 표시.

16.2. 턴 흐름
1턴: OP10. 보병을 첫 거점 방향 한 칸, 정찰은 두 칸 이동. 자원 개발 선택. 캠퍼스 보병 모집 OP5. 종료 RP3, 모집 완료.
2턴: 캠퍼스 OP5 수입. 첫 보병 이동 2번째 칸, 정찰이 자원 발견. 종료 자원 개발 6/6 완료.
3턴: 첫 보병 거점 도착. 조직 훈련 선택. 캠퍼스 자원 개발 OP3 착수. 종료 RP3, 개발 완료.
4턴: 첫 보병 점령. 새 보병은 중앙 방향 이동. 종료 거점 편입, 조직 훈련 완료.
5턴: 거점 OP2와 개발 OP1이 처음 포함. 거점 전문화 연구 선택. 정찰이 적 외곽 흔적 발견. 성대는 공통 기술 두 개 완료 상태.
6턴: 정찰이 다른 대학을 실제 관측, 중립 접촉 알림. 적 접근 방향 확인. 거점 작업은 다음 특화에 대비해 비워도 됨.
7턴: 중앙 목표 접근. 보병 방어/이동 선택. 연구 누적 9/10. 적 예약 명령은 보이지 않음.
8턴: 세 번째 기술 완료, 성대 학문1 획득. 거점 특화는 다음 턴부터 가능. 적과 최초 조우를 배치하되 지도 이동 결과에 따라 발생 여부는 달라짐.
9턴: 경제/연구/군사 중 거점 특화 선택. 새 기술에 학문 할인 사용 안내. 첫 공격·후퇴·휴전 선택.
10턴: 특화 수입/효과 확인. 다음 확장 또는 전선 강화 계획. 튜토리얼 종료 후 자유 진행.

16.3. 자원 예시 검산
위 필수 지출만 수행 시 OP: 1턴 10-5=5, 2턴 10, 3턴 15-3=12, 4턴 17, 5턴 25(5+2+1 수입), 이후 매 턴8. 실제 플레이는 추가 모집/건설 지출을 유도해야 한다. 이 경로에서 OP가 과도하게 남으면 수입을 줄이기 전에 선택지와 작업 슬롯 제약이 원인인지 확인한다. 튜토리얼은 무조건 정해진 OP 잔액을 요구하지 않는다.

17.1. 데이터 구획
CampusVisual: 건물ID/이름/윤곽/높이/도로/지형/출처.

17.2. 판정 구조
render와 game rules를 분리한다. 렌더링 속도·애니메이션 완료 순서가 결과를 바꾸지 않는다. 같은 상태+같은 명령+같은 규칙 버전이면 동일 결과.
온라인은 서버가 잠금·자원·유효성·결과를 확정. 클라이언트는 예약과 예상 결과만 표시. 명령 ID로 중복 처리 방지.

17.3. 저장
싱글은 계획 시작 상태와 예약 명령을 저장. 실행 도중 종료 시 미완료 애니메이션을 재생하거나 건너뛰어 확정 결과로 복귀. 상태가 반쯤 적용된 채 저장되지 않게 원자적 턴 커밋 사용.
저장 버전과 규칙 버전 기록. 호환 불가 저장은 경고하고 임의 변환하지 않는다. 리플레이는 초기 상태·명령·규칙 버전으로 재현.

17.4. 연결 끊김
실시간 친선 후속안: 60초 재접속 유예, 이미 유효 예약한 명령은 유지. 한 턴 미응답은 대기, 연속 3턴 미응답은 기권. 수치는 네트워크 테스트 후 조정. 싱글은 오프라인 저장 가능 구조 우선.

17.5. 성능
건물 개수 보존과 별개로 거리별 세부 장식 조절, 재질 공유, 반복 오브젝트 묶음, 화면 밖 장식 생략. 충돌 판정은 타일·간단 범위만 사용. 목표 프레임·기기 최소 사양은 실제 캠퍼스 장면 측정 후 정한다.

거점·자원 개발·연구·생산·시설·단순 AI·저장. 완료: 시작부터 승리/패배까지 사용자가 완료.

휴전·AI 공동전선·연합 예고. 완료: 플레이어 외 AI도 서로 경쟁, 없는 병력 생성 금지.
P2: 실시간 친선
서버 판정·재접속·명령 제한·중복 방지. 완료: 두 참가자가 같은 결과 확인.
P3: 대학 확장·시나리오·경쟁
다섯 대학, 추가 지도, 시즌. 기본전 재미 확인 뒤 별도 기획.
인력·엔진·자료 상태가 정해지기 전 달력 일정은 산정하지 않는다.

20. 위험·권리·보류 항목

20.1. 권리 검토
원본 데이터·가공·공개 배포·출처 표시·원 코드와 데이터의 별도 조건을 검토한다. 공개 저장소 존재만으로 복제 허용을 가정하지 않는다. 학교명·상징·로고·폰트·음원도 별도 확인. 비공식 창작물 표시와 자료 출처 화면을 준비한다. 문제 있는 자산은 규칙과 분리해 교체 가능하게 한다.

20.2. 범위 밖
해전·항공·종교·시민 배치·자원 거래 시장·장비·병력 경험치·건물 내부 전투·실측 서울 전체·대규모 상시 월드·영구 공격력 성장·유료 능력치·실제 재학생 인증.

20.3. 아직 확정하지 않을 것
최소 기기 사양, 최종 게임 엔진, 호스팅 비용, 실제 제작 일정, 5대학 최종 능력, 경쟁전 매칭 공식, 시즌 기여도, 유료화. 근거 없는 수치 확정을 피하고 시제품 측정 후 결정.

20.4. 기존 문서 대비 주요 수정
개인 육성 후 별도 전투 → 단일 지도 문명형 기본전.
5~10분 전투 → 짧은 시나리오에 한정, 기본전30~45분 가설.
조우전 승자 즉시 진입 → 충돌 정지 후 교전, 추가 이동 없음.
도로 2배 이동 → 초기에는 험지 비용 완화만.
비동기 습격 우선 → 싱글 한 판 완성 우선.
강자에게 새 적 생성 → 기존 AI의 실제 생산·외교 대응.
다섯 고유 자원 강제 → 필요한 대학만 별도 자원.
